# 🇺🇦 Ukraine Territorial MCP

**Open-data infrastructure for Ukraine's territories, communities, and local government — accessible to AI agents through the Model Context Protocol (MCP).**

**[MAIN PROJECT · ГОЛОВНИЙ ПРОЄКТ](https://github.com/Ukraine-Territorial-MCP/ukraine-territorial-mcp)** · **[Live MCP endpoint](https://community.ukrdigital.org/mcp/ukraine/mcp)**

> **Start here.** The [Ukraine Territorial MCP main repository](https://github.com/Ukraine-Territorial-MCP/ukraine-territorial-mcp) is the central location for documentation, integration and ongoing core development. Our other KATOTTG-named repositories are **derived territorial components, prototypes, or works in progress**. They are not separate canonical versions of the national server.

### Project at a glance

| Coverage | Current scope |
|---|---:|
| Ukrainian administrative territorial records (KATOTTG) | **31,744** |
| Available MCP tools (HTTPS verified) | **19** |
| Mapped local councils with EDRPOU and settlement KATOTTG codes | **1,556** |

Explore territorial data, search local councils, and access structured regional and district council records through the national MCP.

**Connect a remote MCP client (Streamable HTTP):**
```text
https://community.ukrdigital.org/mcp/ukraine/mcp
```

### 🧭 Repository guide

- ⭐ **[ukraine-territorial-mcp — MAIN REPOSITORY](https://github.com/Ukraine-Territorial-MCP/ukraine-territorial-mcp)** — official project entry point, documentation, development roadmap and integration details.
- **Territorial repositories named `UA…`** — derived or experimental datasets/components mapped to individual KATOTTG identifiers. Their implementation status varies; primary development happens in the main repository.

## Українською

**Ukraine Territorial MCP («Громади України»)** — проєкт структурованого доступу до даних про адміністративно-територіальний устрій України, органи місцевого самоврядування та відкриті державні дані через MCP.

### ✅ Що вже працює

- Каталог **31 744** територіальних записів КАТОТТГ.
- **19** інструментів MCP, перевірених через публічне HTTPS-підключення.
- **1 556** зіставлених місцевих рад із кодами ЄДРПОУ та КАТОТТГ населених пунктів.
- Інформація про області, райони, громади, населені пункти, обласні та районні ради.
